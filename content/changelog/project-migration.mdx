The migration of the project from ReactJS and Node to Next.js due to performance issues. With this migration, we have seen significant improvements in the overall performance of the application.

In addition to the migration, there are changes related to the app's look and feel in terms of UI and UX, including updates to reflect a new brand name and assets. These changes aim to enhance user experience and make the application more visually appealing while aligning with the rebranding efforts.

Overall, this change represents a substantial update that not only addresses performance issues but also improves the overall appearance, usability, and branding consistency of the application.
